Privacy policy

Blip the AI production tool · last updated 16 October 2026

What the tool is

"Blip the AI" is a private production tool for the YouTube channel @BlipTheAI. It runs on the channel owner's own computer and is used only by the channel's owner. It is not offered to the public, and no other people sign in to it.

What it accesses

With the owner's consent through Google sign-in, the tool uses two Google APIs for the owner's own channel only:

  • YouTube Data API (scope youtube.force-ssl): to upload the channel's videos and set their titles, descriptions, thumbnails, visibility and playlists.
  • YouTube Analytics API (scope yt-analytics.readonly): to read the channel's own performance reports, such as views, watch time and traffic sources.

The tool does not access other people's channels, accounts or private data.

How data is handled

  • Data from these APIs is processed and stored only on the owner's computer.
  • It is not sold, shared with third parties, used for advertising, or used to train AI models.
  • Sign-in tokens are stored locally and are never published.
  • The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Removing it stops the tool from reaching the channel.

Contact

Questions about this policy can be sent through the contact details on the channel's About page.
